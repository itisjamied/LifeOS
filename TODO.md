# UI Audit Follow-Through

Completed items from the app UI audit:

- Long-pressing a habit row opens habit detail/history, while normal tap still expands sub-steps.
- Habit rows now have a right-side complete/clear button for quickly finishing the whole habit.
- Today uses calmer empty states with day context and a route to edit the routine.
- Habit completion keeps the existing check animation/vibration and now gives the whole-row action a clearer affordance.
- Habits can be skipped for today; skipped days are neutral in score, stats, and streaks.
- The routine editor has a real icon picker with preset symbols plus custom emoji/icon input.
- The journal color palette has light and dark theme equivalents for readable rich text.
